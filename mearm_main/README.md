# mearm_main —— meArm 控制主程序（提交用）

任务一 / 二 / 三 / 五 全部功能的**整合工程**，一份可直接编译、烧录、复现视频效果的代码。

> 按任务拆成七个文件，但仍然是**一份工程**：Arduino 编译一个 sketch 目录时，会把
> 目录下所有 `.ino` 自动合并成一个编译单元，顺序为「主文件（与目录同名）在最前，
> 其余按字母序」。因此不需要任何额外配置，打开 `mearm_main.ino` 就能整体编译。
>
> 烧录：Arduino IDE 打开 `mearm_main.ino` → 选板子 Arduino Uno → 上传。

## 文件分工

| 文件 | 内容 |
|---|---|
| `mearm_main.ino` | 公共常量与全局状态、`setup()`/`loop()`、串口接收与分帧、指令派发、`HELP` |
| `kinematics.ino` | 按键扫描、`writeServos()` 安全限位、运动基元、正逆解、`CAL`/`JOG` 标定工具 |
| `task1_basic.ino` | 任务一：摇杆操控、`O`/`S`/`H`/`L`、`x,y,z` 协同 |
| `task2_pick_place.ino` | 任务二：A / B / C 取放点位与六步取放路径 |
| `task2_teach.ino` | 任务二：示教点位记录、保存与按点位运行 |
| `task3_keyboard.ino` | 任务三：按键1 循环夹取、按键2 录制、按键3 回放、按键4 回中 |
| `task5_drawing.ino` | 任务五：绘图引擎、五点示教、折线与 Catmull-Rom 平滑曲线 |

> 注意：拼接顺序带来的约束：**跨文件使用的全局变量必须定义在 `mearm_main.ino`**（它排在最前）。
> 各任务专属的状态变量都放在各自文件里；跨文件的函数原型只允许出现内建类型
> ——Arduino 会把自动生成的函数原型插到合并文件开头，原型里一旦出现自定义结构体，
> 就可能落在结构体定义之前导致编译失败。

```
TEACH          → 摇杆1 把笔尖移到目标点（X=左右，Y=前后）
SET            → 记录第 1 个点（或按 D11）
```

**全过程不需要重新编译或烧录程序**，符合考核要求。

## 画图前必须标定

连杆长度、零点和舵机行程都在 `mearm_main.ino` 顶部定义。换机械臂、拆装舵机臂或改变笔的固定方式后，这些值需要重新测量。

标定流程见 `docs/说明文档.md` 第七节。可以用 `JOG 0 0` 摆出大臂水平、小臂伸直的姿态，再用 `CAL` 读取程序当前算出的笔尖坐标，与实测值对照。

## 舵机安全行程（实测，2026-10-09）

`kinematics.ino` 顶部的 `BASE_MIN/MAX`、`SH_MIN/MAX`、`EL_MIN/MAX`、`GR_MIN/MAX`
由逐度扫描实测得到（各留 3° 余量），**所有舵机输出统一在
`writeServos()` 里被钳制到这些范围内**，任何指令、逆解、摇杆都不可能把关节顶到
机械止点上憋劲。拆装舵机臂后必须重新实测并更新。

> 注意：**夹爪数字的口径是「逻辑角：大 = 张开」**，和舵机原始角正好相反。
> 硬件本身是小角开、大角闭（实测原始角 50 = 开 / 170 = 闭），代码在
> `writeServos()` 这个唯一出口做了一次镜像：`原始角 = 220 − 逻辑角`。
> 全程序其余地方（`GRIP_OPEN`/`GRIP_CLOSE`、`GRIP_CLOSE_OBJ`、`PEN_GRIP`、
> `F<角度>`、`G<0~100>`）一律用**逻辑角**。
> 和舵机原始角对照时换算一次：**逻辑角 = 220 − 原始角**。
>
> 注意：夹爪的下限 `GR_MIN` 不是舵机的机械止点，而是**两爪刚好夹上、不顶**
> 的位置 —— 再往紧一点就是硬碰硬堵转（烧过一次舵机）。所以它与 `GRIP_CLOSE` 取同一个值。

标定流程见 `docs/说明文档.md` 第七节。用 `JOG 0 0` 和 `CAL` 两个指令可以快速校准。

## 资源占用（实测）

Flash 14.1 KB / 32 KB，静态 SRAM 1.0 KB / 2 KB —— Uno 上余量充足。
录制缓冲已按 SRAM 限制压缩为 `uint8_t[200][4]`（12 秒），不要盲目调大 `REC_MAX`。
