# mearm_main

任务一 / 二 / 三 / 五的整合程序。Arduino 编译 sketch 目录时会把同目录的
`.ino` 一起编译（主文件在前，其余按字母序），所以打开 `mearm_main.ino`
就能整体上传，不需要别的配置。

## 文件

- `mearm_main.ino` —— 常量、全局状态、`setup()` / `loop()`、串口收指令和分派
- `kinematics.ino` —— 按键扫描、舵机输出与限位、运动基元、正逆解、`CAL` / `JOG`
- `task1_basic.ino` —— 任务一：摇杆操控、`O` / `S`、`H` / `L`、`x,y,z`
- `task2_pick_place.ino` —— 任务二：A / B / C 取放点位
- `task2_teach.ino` —— 任务二：示教点位，存在 EEPROM 里
- `task3_keyboard.ino` —— 任务三：按键 1~4
- `task5_drawing.ino` —— 任务五：直线、图形、五点示教、平滑曲线

跨文件用的全局变量要写在 `mearm_main.ino` 里，因为它在最前面。

## 串口指令（9600）

| 指令 | 功能 |
|---|---|
| `M` | 进入 / 退出摇杆操控 |
| `O` / `S` | 夹爪张开 / 闭合 |
| `H` / `L` | 速度档 +1 / -1 |
| `x10,y30,z20` | 底座 / 大臂 / 小臂同时转到指定角 |
| `A` / `B` / `C` | 夹取对应物体 |
| `RUN` | 依次夹取 A、B、C |
| `1` / `2` / `3` / `4` | 循环夹取 / 录制 / 回放 / 回中 |
| `LINE` | 直线 |
| `N` / `T` / `Z` / `V` | 字母 N / 三角形 / 字母 Z / 字母 V |
| `TEACH` | 五点示教 |
| `SET` / `CLR` | 记录 / 清空示教点 |
| `DRAW` / `CURVE` | 折线 / 平滑曲线 |
| `DEMO` | 内置五点演示 |
| `PAUSE` / `RESUME` / `CANCEL` | 暂停 / 继续 / 取消 |
| `GO` | 回待机位 |
| `CAL` / `JOG s e` / `JOY` / `HELP` / `STATUS` / `RAM` | 调试 |

## 按键

| 按键 | 引脚 | 功能 |
|---|---|---|
| 暂停 | D2 | 暂停绘制 |
| 继续 | D3 | 从暂停处继续 |
| 取消 | D10 | 终止并回待机位 |
| 示教记录 | D11 | 记录当前笔尖位置 |
| 摇杆 2 按键 | D4 | 录制开始 / 结束 |
| 摇杆 1 按键 | D5 | 回中 |

## 现场演示任务五

```
TEACH          进入示教，摇杆把笔尖移到目标点
SET            记录一个点（也可以按 D11）
...            重复到第 5 个点
DRAW           画折线
CURVE          画平滑曲线
PAUSE / RESUME / CANCEL 或 D2 / D3 / D10
```

全程不用重新烧录。

## 标定

连杆长度、零点和舵机行程都在 `mearm_main.ino` 顶部。换机械臂、拆舵机臂或者
换了笔的固定方式之后要重新测。`JOG 0 0` 摆出大臂水平、小臂伸直，再用
`CAL` 读程序算出的笔尖坐标，和实测值对比。

## 舵机限位

`kinematics.ino` 顶部的 `BASE_MIN/MAX`、`SH_MIN/MAX`、`EL_MIN/MAX`、
`GR_MIN/MAX` 是逐度扫出来的，各留了 3° 余量。所有输出最后都在
`writeServos()` 里钳位，指令和逆解都不会把关节顶到机械止点上。

夹爪用的是逻辑角：数字大 = 张开，和舵机原始角相反。换算在
`writeServos()` 里做，`原始角 = 220 - 逻辑角`。`GR_MIN` 是刚好夹住、
不顶死的位置，再紧就会堵转。

## 资源

Flash 14.1 KB / 32 KB，静态 SRAM 1.0 KB / 2 KB。
录制缓冲是 `uint8_t[200][4]`，约 12 秒，不要再调大 `REC_MAX`。
