# MeArm_control

机器人学院十二期二面考核 · 算法（控制、视觉）方向

基于 meArm 机械臂套件的 Arduino 控制项目仓库。

## 目录结构

| 目录 / 文件 | 对应任务 | 说明 |
|---|---|---|
| **`mearm_main/`** | 任务一 / 二 / 三 / 五 | ⭐ **提交用主工程**：一份可直接编译烧录的工程，按任务分成六个 `.ino` |
| ├ `mearm_main.ino` | — | 主文件：公共常量与全局状态、`setup()`/`loop()`、串口接收、指令派发 |
| ├ `kinematics.ino` | 公共 | 按键扫描、舵机驱动与安全行程限位、运动基元、正逆运动学、标定工具 |
| ├ `task1_basic.ino` | 任务一 | 摇杆实时操控、固定指令 `O`/`S`/`H`/`L`、多舵机协同 `x,y,z` |
| ├ `task2_pick_place.ino` | 任务二 | A / B / C 夹取与放置 |
| ├ `task3_keyboard.ino` | 任务三 | 按键1 循环夹取、按键2 录制、按键3 回放、按键4 回中 |
| └ `task5_drawing.ino` | 任务五 | 直线、基础图形、过程控制、五点示教折线 / 平滑曲线 |
| **`remote_serial/`** | 任务三 | ⭐ **提交用串口通信工程**：电路组按键遥控板的发送端 |
| `tools/mearm_range_test/` | — | 标定工具：逐度扫描测出各关节的实际安全行程 |
| `docs/` | — | **说明文档**、**提交清单**、任务四运动学推导文档 |

> 演示与提交请统一使用 `mearm_main/` 与 `remote_serial/`。
> `mearm_main/` 是**一份工程**：Arduino 编译时会把同目录下所有 `.ino` 自动按
> 「主文件 → 其余字母序」合并成一个编译单元，所以拆成多个文件后仍然是
> 「一份可直接编译、烧录和复现视频效果的工程」，无需任何额外配置。

## 快速开始

1. 用 Arduino IDE 打开 `mearm_main/mearm_main.ino`，编译烧录到机械臂主控板（Arduino Uno）。
2. 串口监视器波特率设为 **9600**，行尾选"换行符"。
3. 发送 `HELP` 查看全部指令，发送 `CAL` 查看笔尖坐标。
4. 画图前请先按 `docs/说明文档.md` 第七节完成几何参数标定。

## 硬件接线

```
舵机   底座 D9      大臂 D7      小臂 D8      夹爪 D6
摇杆   X1=A0  Y1=A1  X2=A2  Y2=A3     摇杆按键 D5 / D4
本地按键（一端接引脚，一端接 GND）  暂停 D2  继续 D3  取消 D10  示教记录 D11
```
