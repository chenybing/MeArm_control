# MeArm_control

机器人学院十二期二面考核 · 算法（控制、视觉）方向

基于 meArm 机械臂套件的 Arduino 控制项目仓库。

## 目录结构

| 目录 | 对应任务 | 说明 |
|---|---|---|
| **`mearm_main/`** | 任务一 / 二 / 三 / 五 | ⭐ **提交用主工程**：全部功能整合为一份可直接编译烧录的工程 |
| **`remote_serial/`** | 任务三 | ⭐ **提交用串口通信工程**：电路组按键遥控板的发送端 |
| `mearm_control/` | 任务一 | 开发记录：基础控制（摇杆操控）、关节活动范围测试 |
| `serial_comm/` | 任务一 | 开发记录：固定指令 O/S/H/L、多舵机协同 x,y,z |
| `task2_pick_place/` | 任务二 | 开发记录：A/B/C 夹取与放置 |
| `task3_keyboard/` | 任务三 | 开发记录：按键输入（早期版本，完整逻辑见 `mearm_main`） |
| `task5_drawing/` | 任务五 | 开发记录：逆运动学绘图、Catmull-Rom 平滑曲线（早期版本） |
| `docs/` | — | **说明文档**、**提交清单**、任务四运动学推导文档 |

> 演示与提交请统一使用 `mearm_main/` 与 `remote_serial/`；
> 其余目录是按功能点分步开发的中间版本，保留作为开发过程记录。

## 快速开始

1. 用 Arduino IDE 打开 `mearm_main/mearm_main.ino`，编译烧录到机械臂主控板（Arduino Uno）。
2. 串口监视器波特率设为 **9600**，行尾选"换行符"。
3. 发送 `HELP` 查看全部指令，发送 `CAL` 查看笔尖坐标。
4. 画图前请先按 `docs/说明文档.md` 第七节完成几何参数标定。

## 硬件接线

```
舵机   底座 D9      大臂 D7      小臂 D8      夹爪 D6
摇杆   X1=A0  Y1=A1  X2=A2  Y2=A3     摇杆按键 D5 / D4
本地按键（一端接引脚，一端接 GND）  暂停 D2  继续 D3  取消 D10  示教记录 D11
```
