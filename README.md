# MeArm_control

机器人学院十二期二面考核 · 算法（控制、视觉）方向

基于 meArm 机械臂套件的 Arduino 控制项目仓库。

## 任务目录

| 目录 | 对应任务 | 说明 |
|---|---|---|
| `mearm_control/` | 任务一 | 基础控制：关节独立移动、摇杆实时操控、多舵机协同 |
| `serial_comm/` | 任务一 | 串口通信：固定指令 O/S/H/L、x,y,z 多舵机指令 |
| `task2_pick_place/` | 任务二 | A/B/C 物体夹取与放置（联动机械方向） |
| `task3_keyboard/` | 任务三 | Arduino 按键遥控板联动（联动电路方向） |
| `task5_drawing/` | 任务五 | 轨迹绘制与画图：直线、图形、五点示教 |
| `docs/` | 任务四等 | 运动学正逆解推导、说明文档等（备份） |

## 开发记录

每完成一个功能点提交一次；重要功能使用分支开发后合并回 main。
