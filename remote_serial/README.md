# remote_serial —— Arduino 按键遥控板固件（提交用）

任务三「串口通信」侧的代码：跑在电路组自制的按键遥控板上，
捕获 4 个按键并通过串口把指令发给机械臂主控（`mearm_main`）。

## 指令协议

| 按键 | 发出的指令 | 机械臂动作 |
|---|---|---|
| 按键1 | `1\n` | 循环夹取 A → B → C → A … |
| 按键2 | `2\n` | 录制开始 / 结束（摇杆操控，>10 秒） |
| 按键3 | `3\n` | 回放上次录制的动作 |
| 按键4 | `4\n` | 回中 |

机械臂每切换状态会回传一行 `STAT:xxx`（`IDLE` / `MANUAL` / `REC` / `PLAY` / `TEACH` / `DRAWING` / `PAUSED`），
可用于驱动遥控板上的 OLED 显示。

## 接线

```
遥控板 TX  →  机械臂 D0(RX)
遥控板 RX  →  机械臂 D1(TX)      （可选，用于接收状态显示到 OLED）
遥控板 GND →  机械臂 GND          （必须共地！）
```

## 两个现场最容易翻车的坑

1. **USB 抢总线**：机械臂用的是硬件串口 D0/D1，与板载 CH340 并联。
   若机械臂还插着 USB 线，CH340 的 TX 会和遥控板的 TX 一起驱动 D0，双方互相打架 → 指令乱码或收不到。
   → **演示任务三时拔掉机械臂的 USB 线，改用外接 5V 供电。**
   → 若必须同时插 USB，把 `mearm_main.ino` 顶部的 `REMOTE_SOFT_SERIAL` 改成 `1`，改用软串口 D12/D13 接遥控板。

2. **不共地**：两块板子必须共地，否则 5V 电平没有共同参考，收到的全是乱码。

## 按键引脚

`remote_serial.ino` 顶部默认 `D2 / D3 / D4 / D5`：
**必须向电路方向的同学核对他们画板时的实际引脚**，改这 4 个常量即可。
若按键是"按下读到 HIGH"（下拉 + 接 VCC），把 `KEY_ACTIVE_LOW` 改成 `false`。

## 调试技巧

把遥控板的 USB 接到电脑，串口监视器 9600 能直接看到：
- `发送指令 → 1`：遥控板确实发出去了
- 后面跟着的 `STAT:xxx`：机械臂回传的状态

这样一旦不通，立刻能判断是"遥控板没发"还是"机械臂没收到"。
