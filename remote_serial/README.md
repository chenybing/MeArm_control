# remote_serial

按键遥控板的程序。按下按键后通过串口把对应指令发给机械臂主控。

## 按键

| 按键 | 发出 | 动作 |
|---|---|---|
| 1 | `1` | 循环夹取 A → B → C |
| 2 | `2` | 录制开始 / 结束 |
| 3 | `3` | 回放 |
| 4 | `4` | 回中 |
| 5 | `PAUSE` | 暂停 |
| 6 | `RESUME` | 继续 |
| 7 | `CANCEL` | 取消 |
| 8 | `SET` | 记录示教点 |

机械臂状态变化时会回一行 `STAT:xxx`，可以用来驱动 OLED。

## 接线

引脚在 `remote_serial.ino` 顶部：按键 1~4 接 A0~A3，按键 5~8 接 D5~D8。
按键默认低电平有效，如果按下读到 HIGH，把 `KEY_ACTIVE_LOW` 改成 `false`。

```
遥控板 TX  →  机械臂 D0(RX)
遥控板 RX  →  机械臂 D1(TX)      可选，用来收状态
遥控板 GND →  机械臂 GND          必须共地
```

## 注意

机械臂的 D0/D1 和板载 CH340 是并联的。如果机械臂还插着 USB，CH340 的 TX
会和遥控板的 TX 一起驱动 D0，指令会乱码或收不到。

演示任务三时拔掉机械臂的 USB，改用外接 5V。必须同时插 USB 的话，把
`mearm_main.ino` 顶部的 `REMOTE_SOFT_SERIAL` 改成 `1`，用 D12/D13 软串口。

两边不共地也会全是乱码。
