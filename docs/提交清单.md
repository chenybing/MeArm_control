## 二、必须做的三件事（不做会影响得分）

### 1. 标定几何参数（决定任务五能不能画准）

打开 `mearm_main/mearm_main.ino`，改顶部这一段：

```cpp
const float ARM_L1 = 8.0;        // 量：肩关节轴 → 肘关节轴
const float ARM_L2 = 8.0;        // 量：肘关节轴 → 笔尖（不是腕中心！）
const float H_SHOULDER = 6.0;    // 量：肩关节轴离桌面的高度
```

然后按 `docs/说明文档.md` 第七节校准方向（`SHOULDER_INVERT` / `ELBOW_INVERT` / `BASE_INVERT` / `TRIM`）。

校准用指令：`JOG 0 0`（大臂水平前伸、小臂完全伸直）、`CAL`（打印程序认为的笔尖坐标）。

### 2. 调任务二 / 任务五的点位常量

`PICK_U/V[]`、`PLACE_U/V[]`（任务二取物位 / 放置位）和绘图区域常量都按**你桌面的实际摆放**修改。
把机械臂手动摆到物体正上方，用 `CAL` 读出 `(u, v)` 填进去最快。

### 3. 和电路组联调任务三

需要确认三件事：

- [ ] **遥控板的按键引脚**：`remote_serial.ino` 顶部默认 D2/D3/D4/D5，**必须向电路方向的同学核对实际引脚**

联调通过的标准：按遥控板按键 1，机械臂夹取物体 A；再按一次夹 B；再按一次夹 C。
